# 金融小助手 HTML 产品展示

这是动态产品展示页，适合全屏讲解。新版共 16 页，团队页前置，包含产品定位、市场痛点、运行截图、系统架构图、可信数据层、沉浸式体验、技术壁垒、成员照片与团队分工。

## 使用方式

1. 双击打开 `index.html`。
2. 使用 `←` / `→` / `Space` 切换页面。
3. 按 `F` 进入或退出全屏。
4. 触控屏可左右滑动切换。

## 展示风格

- 内容更偏高层表达：市场数据中台、数据可信层、可观测性、韧性缓存、沉浸式可视化、零成本分发。
- 刻意减少接口细节和实现碎片，突出产品价值、技术路线和创新创业可扩展性。
- 页面完全静态，无外部 CDN，直接本地打开即可展示。
- 团队页会读取 `member_pic/` 中的史健申、钟浩、曹桂涛照片。

## 建议讲解顺序

1. 先用 HTML 展示页讲项目定位与价值。
2. 再打开真实产品 `http://127.0.0.1:18765` 做功能验证。
3. 最后用“公开访问金融小助手.bat”生成公网链接，让外部用户用自己的设备访问真实产品。
